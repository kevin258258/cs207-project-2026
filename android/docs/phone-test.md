# 安卓手机测试

这个版本可以在 Android 8.0 或更高版本上安装。它在手机里运行模拟板，打开 App 即可测试。

## 安装

1. 解压交付 ZIP，打开其中的 `EGO1-Puzzle-0.1-debug.apk`。
2. 如果系统要求授权安装，给当前打开 APK 的文件管理器授权，然后继续安装。
3. 如果手机已有同名试用版，系统提示签名不匹配时，卸载旧版后再安装。

## 快速验收

| 操作 | 预期结果 |
| --- | --- |
| 点「练习关」 | 棋盘为 `123456708`，`5`、`7`、`8` 高亮，两项步数为 `0` |
| 点 `1` | 棋盘保持原样，显示无法移动，无效步数为 `1` |
| 点「撤回」 | 无效步数回到 `0` |
| 再点 `1`，然后点 `8` | 棋盘变为 `123456780`，显示通关，有效和无效步数各 `1` |
| 点「查看统计」 | 显示通关统计，两项各 `1` |
| 点「复位」 | 棋盘清空，计数归零，可从第 1 格重新摆盘 |
| 连续输入两次 `1` | 第二格显示 `E`，继续输入 `2` 可以纠正 |
| 点「开始演示」，随后点四次「演示下一步」 | 依次看到开局、非法落子、通关、统计、复位 |

## 已验证的范围

- 调试 APK 完成 Gradle 构建和签名校验，并在 Android 16（API 36）模拟器上安装、运行和点击验收。
- EGO1 Lab 9 在 Vivado 2018.3 中通过按键消抖、单步计数、溢出回零、数码管段码和复位仿真。
- EGO1 Lab 10 在 Vivado 2018.3 中通过 UART 回环仿真，核对了 `48`、`83`、`2A` 三个字节。
- 本机的 Vivado Hardware Manager 未检测到 JTAG 目标。手机与 EGO1 实板的双向联调需要已连接的板卡、华容道 FPGA 工程和双方约定的通信协议。
