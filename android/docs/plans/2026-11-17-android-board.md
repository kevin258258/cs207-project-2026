# EGO1 安卓端第一版

**目标**　做出可安装的安卓 App，练习手机输入、棋盘同步和课程演示。

1. 在 `BoardLink.java` 定义命令和状态。手机提交操作，界面只根据收到的状态更新。将来由硬件连接实现这个接口。
2. 在 `SimulatedBoard.java` 模拟 FPGA 的初始化、落子、提示、计数、撤回、通关、复位和五步演示。用课程样例和边界格检查游戏规则。
3. 在 `MainActivity.java` 做二维棋盘和控制区。构建调试 APK，检查开局、非法点击和通关流程。
4. 拿到板端协议后实现真实连接。两边交替操作，核对棋盘和统计，并验证断线期间不显示未经板端确认的落子。
